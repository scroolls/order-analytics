# Аналитика заказов и возвратов

Pet-проект для анализа выгрузки заказов интернет-магазина. Он проверяет входные данные, рассчитывает показатели в SQL и собирает Excel-отчёт с динамикой выручки, возвратов и сроков доставки. Подготовленная таблица и меры DAX позволяют собрать те же показатели в Power BI.

В репозитории лежит **синтетическая** выгрузка для демонстрации работы. Цифры в примере не описывают результаты реального магазина. Вместо неё можно подставить собственный CSV-файл того же формата.

## Что показывает отчёт

- Количество заказов, завершённых заказов, отмен и возвратов.
- Выручку после возвратов: учитываются только доставленные и не возвращённые заказы.
- Долю возвратов среди завершённых заказов и долю доставок позже обещанного срока.
- Динамику по месяцам, показатели по категориям, регионам и каналам.
- Медианный и 90-й процентиль срока доставки, а также 95% интервал для доли возвратов.

## Быстрый запуск

Нужен Python 3.11 или новее. Команды выполняются из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python src/run_analysis.py
```

После запуска появятся `reports/report.xlsx`, `reports/summary.json`, таблицы с показателями и `reports/power_bi/orders.csv`. Готовый пример Excel-отчёта также сохранён в [`examples/report.xlsx`](examples/report.xlsx).

Чтобы заново создать демонстрационную выгрузку:

```powershell
python src/generate_sample.py
python src/run_analysis.py
```

Для своей выгрузки:

```powershell
python src/run_analysis.py --input путь\к\orders.csv --output путь\к\отчётам
```

## Формат входного CSV

Одна строка — один заказ. Обязательные столбцы:

| Столбец | Значение |
| --- | --- |
| `order_id`, `customer_id` | Идентификаторы заказа и клиента |
| `order_date`, `promised_date`, `delivered_date` | Даты в формате `YYYY-MM-DD`; у отмены дата доставки пустая |
| `channel`, `region`, `category` | Канал продажи, регион и категория товара |
| `qty`, `unit_price` | Положительное целое количество и цена за единицу |
| `status` | `delivered`, `returned` или `cancelled` |

При ошибке в структуре, повторе `order_id`, неверной цене или противоречивых датах обработка останавливается с понятным сообщением. Ошибочные строки не удаляются молча.

## Как устроен расчёт

1. [`src/analysis.py`](src/analysis.py) читает CSV, проверяет его и добавляет вычисляемые поля: сумму заказа, месяц, признак возврата и просрочки.
2. [`sql/metrics.sql`](sql/metrics.sql) считает месячные и сегментные показатели. Для запуска запросов используется встроенная в Python SQLite; отдельный сервер базы данных не нужен.
3. Python рассчитывает медиану, 90-й процентиль и интервал Уилсона для доли возвратов.
4. [`src/report.py`](src/report.py) записывает Excel-отчёт с графиками, CSV для Power BI и краткий итог в JSON.
5. Перед сохранением итоговая выручка и число заказов сверяются с помесячной таблицей.

Возвраты и просрочки показаны как наблюдаемые показатели. Данные проекта не позволяют утверждать, что просрочка *вызывает* возврат. Интервал для доли возвратов показывает статистическую неопределённость оценки, но не делает синтетическую выборку репрезентативной для реального бизнеса.

## Power BI

Импортируйте `reports/power_bi/orders.csv` через **Получить данные → Текст/CSV** и назовите таблицу `orders`. Укажите тип *Дата* для столбцов с датами, тип *Десятичное число* для `amount` и *Целое число* для флагов `is_return`, `is_completed`, `is_late`. Создайте меры из [`power_bi/measures.dax`](power_bi/measures.dax) по одной через **Новая мера**.

Для компактной страницы отчёта достаточно карточек «Выручка после возвратов», «Доля возвратов», «Доля доставок позже срока», графика по `month` и таблицы по `category` или `region`. Файл `.pbix` в репозиторий не включён; CSV и меры подготовлены для самостоятельной сборки отчёта в Power BI Desktop.
